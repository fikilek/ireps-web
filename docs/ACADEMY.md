# Academy documentation ownership

[iREPS Academy](https://github.com/fikilek/ireps-academy/blob/main/README.md) owns user manuals, learner-facing explanations, training scripts and the master dictionary. This repository retains application code, technical designs, tests and release evidence.

Use the [contribution process](https://github.com/fikilek/ireps-academy/blob/main/00-academy-governance/CONTRIBUTING.md) and [master dictionary](https://github.com/fikilek/ireps-academy/blob/main/15-dictionary/iREPS_Master_Dictionary.md). SPU means **Super User**. Guest is excluded from the current training role catalogue. Permission inheritance, common offline behaviour and QA still require product decisions.

Runtime help rendering and calculations stay in the application. Academy owns their educational wording; integrate wording changes through the relevant development and release process.

Some guide links refer to material imported from feature branches. Their presence on main does not mean those features are deployed. Feature worktrees can retain historical document copies until their owners integrate this documentation commit. When merging such branches, retain the Academy links and contribute new instructional details to Academy rather than restoring duplicate manuals.
